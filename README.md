# Baby Steps — public site

The privacy policy and support pages for the Baby Steps Android app, served by
GitHub Pages at <https://montivagant.github.io/baby-steps-site/>.

These pages are **generated**, not hand-written. The privacy policy is rendered
from `docs/PRIVACY-POLICY.md` in the app's own (private) repository by
`tool/build_site.py`, so the published page and the document the app is built
against cannot drift apart. Edit the policy there and regenerate; do not edit the
HTML here.

The app repository is private because it carries product strategy and store
submission notes. Only what a user or a store reviewer needs to read is here.
